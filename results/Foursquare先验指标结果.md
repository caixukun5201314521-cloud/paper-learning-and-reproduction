## 各指标明细

### 1. 活动周期性(式 1–3)

数据集级日计数序列共 **138 天**(2011-12-08 ~ 2012-04-23,与论文"5 个月"一致)。
三种粒度分别计算 φ:日 0.2853、周 0.2895、月 0.1866;按式(1)取最大 → **0.2895(周粒度)**。

**⚠ 重要数据质量发现(2026-11-03 复查)**:完整日序列(见 `results/foursquare_daily_series.csv`)显示
**138 天中仅 56 天有签到,82 天为零**,且非随机缺失——数据呈约 8 段"脉冲式"采集窗口
(如 12-08~14、12-22~27、01-23~31、04-06~23),最长连续活跃段仅 18 天(04-06 ~ 04-23)。
这与该数据集经 Twitter 间歇抓取的构建方式一致:零天是**采集方没抓,不是用户没签**。

后果:段间相关被"共享零段"系统性抬高,且 7 天零块会人为制造周尺度相似。三种算法对比如下:

| 算法 | 序列 | φ_日 | φ_周 | φ_月 |
|---|---|---|---|---|
| A 原始(含零天) | 138 天 | 0.2853 | 0.2895 | 0.1866 |
| B 剔除零天 | 56 天 | **0.3765** | 0.2598 | N/A(<60 天无月窗) |
| C 最长连续段(04-06~23) | 18 天 | **0.6088** | 0.0499 | N/A |

**修正后的解读**:剔除采集污染后,**日粒度**相似度最高(A→B/C 最优粒度从周变为日),
"周粒度最优"的原结论在数据集级**不稳健**。真正稳健的周信号证据来自按星期汇总:
有效日中周六均值 25,871 / 周日 22,795 / 周五 20,087,明显高于周三 9,880 / 周二 10,618
(周末出行效应,与常识相符),但每个星期几的有效天数仅 5~10 天,样本有限。

**说明①(修订)**:与论文 0.112 的差异来自三重叠加:(a)脉冲式采集污染(上述);(b)式(2)步长 k
的实现选择;(c)论文可能在用户级子样本(27,304 人)上计算而非全量数据集级。本次复现的教训:
**先画完整日序列、识别采集结构,再算周期性**——这本身也是对论文 4.2.1 结论的一次独立检验。

### 2. 活动多样性(式 4)

对 93,418 名签到 ≥3 个场所的用户计算 GS-score 代理(**1 − 归一化熵**:0=通才、1=专才),
GMM 双峰拟合得两组均值 0.0125 / 0.1429,两组 Wasserstein 距离 = **0.1304**。

**说明②**:原版 GS-score(Waller & Anderson)基于**社区嵌入**度量"兴趣广度",需要 gensim/node2vec(本机 Python 3.14 无法安装);熵代理只看"去过多少不同场所"。由于人均签到仅约 2 次、多数用户每个场所只去一次,熵代理天然偏低(均值 0.029),与论文"Foursquare 得分接近 1"的刻画不同属**代理语义差异**而非数据差异。要完全对齐需补 Python 3.12 环境后换原版 GS-score。

### 3. 图结构(式 6)

从 485,381 名活跃签到用户中随机抽 30,000 人,流式扫描 2,710 万条好友边,保留两端均在抽样集内的边构成诱导子图(2,528 节点 / 2,337 边),`nx.average_clustering` = **0.0399**。

**说明③**:在 215 万节点的全图上抽 0.014% 的点做诱导子图,用户的好友大多落在抽样集外,三角形被大量破坏,聚类系数**系统性低估**(期望只保留约 0.02% 的边)。精确值需在 27M 边全图上计算聚类系数(内存与算力成本高,或改用 ego 网络法)。论文值 0.105 高于本次估计,与该偏差方向一致。

### 4. 交互情感(式 7)

评分分布:2 分 1,016,504 / 3 分 246,642 / 4 分 629,216 / 5 分 917,218(共 2,809,580,无 1 分)。
按 s=(r−1)/4 映射到 [0,1]、中性值 0.5、偏移权重 |s−0.5| 计算 **偏置熵 E = 0.5172**。

**说明④**:原 PDF 中式(7)的排版在文本提取时损坏,指数与对数底均按上下文重构,论文值 0.072 与本实现的绝对值**不可直接比较**;但"评分分布远离均匀、携带强偏好信号"这一定性结论与论文一致(2 分与 5 分合计占 69%)。

## 结论

四个可计算指标中,**语言(N/A)与论文完全一致**;周期性在剔除脉冲式采集污染后最优粒度由周变为日,数据集级结论不稳健(真正的周信号体现为星期均值上的周末效应);多样性、图结构、情感的数值差异均可归因于已注明的实现差异(代理指标 / 抽样 / 公式重构),不影响框架演示。完整数值对齐需要:原版 GS-score(需 Python 3.12)、全图聚类系数、以及向作者确认式(7)的精确定义与周期性的用户级计算细节。

**复现方法论收获**:对该数据集先做完整日序列体检(发现 82/138 零天)再解读指标,避免把采集伪影当作行为周期——这一步论文未提及,但其 27,304 人子样本可能恰好规避了此问题。
