## 各指标明细

### 1. 活动周期性(式 1–3)

数据集级日计数序列共 **138 天**(2011-12-08 ~ 2012-04-23,与论文"5 个月"一致)。
三种粒度分别计算 φ:日 0.2853、周 0.2895、月 0.1866;按式(1)取最大 → **0.2895(周粒度)**。

论文 4.2.1 对 Foursquare 的判断是"仅在周粒度上表现出周期性"——本次复现中周粒度确实最优、月粒度明显最弱,**方向吻合**。

**说明①**:论文未给出式(2)中步长 k 的具体范围与分段对齐细节,本次实现取"全部非重叠分段、所有段对 |皮尔逊| 平均、p = k·g 全部取值再平均",窗口集合不同导致 φ 的绝对值普遍高于论文,但粒度间的相对排序不受影响。

### 2. 活动多样性(式 4)

对 93,418 名签到 ≥3 个场所的用户计算 GS-score 代理(**1 − 归一化熵**:0=通才、1=专才),
GMM 双峰拟合得两组均值 0.0125 / 0.1429,两组 Wasserstein 距离 = **0.1304**。

**说明②**:原版 GS-score(Waller & Anderson)基于**社区嵌入**度量"兴趣广度",需要 gensim/node2vec(本机 Python 3.14 无法安装);熵代理只看"去过多少不同场所"。由于人均签到仅约 2 次、多数用户每个场所只去一次,熵代理天然偏低(均值 0.029),与论文"Foursquare 得分接近 1"的刻画不同属**代理语义差异**而非数据差异。要完全对齐需补 Python 3.12 环境后换原版 GS-score。

### 3. 图结构(式 6)

从 485,381 名活跃签到用户中随机抽 30,000 人,流式扫描 2,710 万条好友边,保留两端均在抽样集内的边构成诱导子图(2,528 节点 / 2,337 边),`nx.average_clustering` = **0.0399**。

**说明③**:在 215 万节点的全图上抽 0.014% 的点做诱导子图,用户的好友大多落在抽样集外,三角形被大量破坏,聚类系数**系统性低估**(期望只保留约 0.02% 的边)。精确值需在 27M 边全图上计算聚类系数(内存与算力成本高,或改用 ego 网络法)。论文值 0.105 高于本次估计,与该偏差方向一致。

### 4. 交互情感(式 7)

评分分布:2 分 1,016,504 / 3 分 246,642 / 4 分 629,216 / 5 分 917,218(共 2,809,580,无 1 分)。
按 s=(r−1)/4 映射到 [0,1]、中性值 0.5、偏移权重 |s−0.5| 计算 **偏置熵 E = 0.5172**。

**说明④**:原 PDF 中式(7)的排版在文本提取时损坏,指数与对数底均按上下文重构,论文值 0.072 与本实现的绝对值**不可直接比较**;但"评分分布远离均匀、携带强偏好信号"这一定性结论与论文一致(2 分与 5 分合计占 69%)。

## 结论

四个可计算指标中,**周期性(最优粒度=周)与语言(N/A)两个与论文定性完全一致**;多样性、图结构、情感的数值差异均可归因于已注明的实现差异(代理指标 / 抽样 / 公式重构),不影响框架演示。完整数值对齐需要:原版 GS-score(需 Python 3.12)、全图聚类系数、以及向作者确认式(7)的精确定义。
